## 续费规则和真实成本

目前唯一能把长期成本算得很死的是99元e实例：2026年新购，可以在2027年、2028年、2029年（3月31日前）各续费一次，每次都是99元。首年加三次续费一共396元，用满4年，折合约0.27元一天——对比它1507.56元/年的日常标价，差了十几倍。

规则里有三条要记住：

1. 同一认证主体（个人或企业）同一时间只能保有1台99元实例；如果把这个优惠权益用在了别的实例上，原实例就不再享受99元续费。
2. 这个价格不能叠加任何代金券、优惠券——反正也叠不上，不用费劲凑券。
3. 活动本身截止2029年3月31日，之后是否延续、怎么续，以官方页面为准。

轻量这边，38元、68元、199元都属于新用户活动价，续费价格以续费页实际显示为准。这也是为什么“想长期用”和“想省钱试水”是两条路：前者选99元这种明码标价的续费同价机器，后者先花38元用一年再说。

另外，ECS类实例到期后还有15天宽限期，期间可以续费、数据保留，第16天0点起自动释放。系统默认会在到期前7天、3天、1天、当天和释放前一天发提醒，正常使用很难裸奔到数据被清。

## 常见问题

**38元一年是长期价格吗？**

不是。它是限量抢购价，每天10点和15点各一场；同配置的日常优惠价是68元/年。两档都只对新用户开放。

**老用户还能买到便宜的轻量吗？**

38元这档不行，新用户资格卡得很严。老用户的低成本路径是99元/年的e实例（新老同享、续费同价），或者u1、u2i实例的新人首购3折折扣。

**轻量应用服务器和云服务器ECS有什么区别？**

轻量面向建站、Web应用、容器环境这类场景，主打开箱即用、快速部署；ECS是完整形态的云服务器，规格和配套（数据库、存储、安全）更全，99元e实例就是ECS的入门规格。个人建站选轻量，2核2G配200M峰值带宽在同价位上很难找到对手；要做开发测试、自己搭配套，选e实例。

**服务器到期后数据会马上没吗？**

不会立刻。ECS类实例到期后15天内可续费、数据保留，第16天0点起自动释放，期间系统会多次发送提醒。
